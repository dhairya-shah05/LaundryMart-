# Task 20: JS Mini Project - Laundry Service Web Application

A web application for LaundryMart website made using HTML, CSS and JS. Users can see and explore many of the services listed in the services section and book them. If booking is successful, they recieve an email containing their booking details like user's email, name, phone number, services they booked and the total amount.

## Features

- A responsive navigation bar that lets user navigate through the entire website.
- A service booking section where users can add or remove a particular service according to their preferences and book them.
- A booking form that collects user's contact details and sends them email with the booking details
- The cart is reset after booking is successful.
- A newsletter section where users can subscribe to teh website's newsletter.

## Technologies Used

- HTML
- CSS
- JS

## How To Run

- Open index.html in a browser. Then:
1. Click on the various links in the navigation bar to test the navigation
2. Scroll down to service booking section and try adding few services by clicking 'Add Items' button to see if the cart and total amount are updating in real time or not.
3. Also try removing the items you added to check whether total amount gets updated or not.
4. In the booking form below the cart, type your details and click on 'Book Now' and check your email in-box. You should receive an email with the booking details.
5. Footer of the website contains contact details of the website in case if you need any help.
